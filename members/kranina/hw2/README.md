# HW2: Encode - Zlata Kranina (Sparse Signals)

## Вопрос

Помогает ли открытая LLM восстановить пустые поля описаний активов (сектор, отрасль, регион) по названию и повышает ли это nDCG@10 энкодера курса на FAR-Trans? Сравнение p_infer (вывод полей) с p_para (только пересказ известных полей) при одинаковых модели, TF-IDF, пользователях и разбиении. Группа: 54 клиента, у которых в истории есть актив с пустым сектором или отраслью; 8 из них с покупками в окне.

## Что изменено

Только один фрагмент промпта в `encoder.py` (функция `inference_prompt`): вместо `unknown stays unknown;` добавлена просьба заменить пустые поля значениями, прямо следующими из названия актива (сектор, отрасль, регион), с двумя вымышленными примерами. Всё остальное — модель, TF-IDF, профиль клиента, протокол — без изменений. `data_adapter.py` и `runtime.py` не включены: они побайтно совпадают с файлами курса (сверено SHA-256).

## Модель и ревизия

- `Qwen/Qwen3-4B-Instruct-2507`, ревизия `cdbee75f17c01a7cc42f958dc650907174af0554`.
- greedy (`do_sample=false`), thinking off, контекст 8192, до 160 новых токенов.
- 1534 генерации (767 активов x 2 промпта), 0 fallback, 0 копий исходного JSON.
- protocol_hash `50efd4aeb415ba6f0c66dd0793a7c2033cdc32a42b86b58eebbca3e81eaf3417`.

## Как запустить

В Colab открыть `full_colab.ipynb` и выполнить ячейки по порядку: установка `transformers==4.57.6` и проверка GPU, монтирование Google Drive и восстановление кэша, загрузка файлов, запуск `full_run.py` с зафиксированными моделью и ревизией через `--resume`, проверка результатов. После отключения повторите ячейки 1-3 и затем 4-8. Пилот на 20 активах — `pilot_colab.ipynb` (метрики не считаются).

Для запуска нужны файлы курса `data_adapter.py`, `runtime.py`, `starter.py` и четыре CSV из FAR-Trans — они здесь не лежат согласно разделу ниже.
